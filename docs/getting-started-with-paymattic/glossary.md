# Glossary

New to Paymattic? This glossary brings together all the key terms, features, and concepts you will encounter while building forms, managing payments, and exploring integrations with Paymattic.

## **A**

* **Access Token / API Key / Signature Key:** Secret credentials a payment gateway issues so Paymattic can securely connect to your account. Copy these from your gateway's dashboard into **Paymattic** → **Payment Gateway**.

* **ActiveCampaign Integration:** Connects Paymattic to [ActiveCampaign](/integrate-activecampaign), automatically adding contact information from your form submissions to your ActiveCampaign lists.

## **C**

* **Cancel Subscription:** Lets an admin or customer manually stop an active recurring payment. Read the [Cancel Subscription](/cancel-subscription) documentation.

* **Cloudflare Turnstile:** A CAPTCHA-free bot and spam protection layer you can enable on forms. Read the [Cloudflare Turnstile](/configure-cloudflare-turnstile) documentation.

* **Conditional Logic:** A rules engine that shows, hides, or triggers actions based on what a user has entered. Read the [Conditional Logic](/use-conditional-logic) documentation.

* **Confirmation:** The message, redirect, or action shown to a user right after they submit or pay on a form. Configure it under **Settings** → **Confirmation**.

* **Coupon:** A field for creating discount codes visitors can apply at checkout to reduce their total. Read the [Coupon Field](/add-coupon-field) documentation.

* **Currency Switcher:** Lets donors/customers pick which currency to pay or donate in. Read the [Currency Switcher](/add-currency-switcher) documentation.

* **Custom CSS/JS:** A per-form panel for adding your own CSS or JavaScript without affecting other forms.

* **Custom Payment Gateway:** Lets you build and add a payment method not supported out of the box. Read the [Custom Payment Gateway](/create-a-custom-payment-gateway) documentation.

* **Customer/Donor Profile:** A record Paymattic builds for every payer, showing subscriptions and payment history. Read the [Customer Profile](/view-customer-profile) documentation.

## **D**

* **Donation Leaderboard:** A public display that ranks your top donors to encourage more contributions. Read the [Donation Leaderboard](/add-donation-leaderboard) documentation.

* **Donation Progress:** A progress bar field showing how much of a fundraising goal has been collected. Read the [Donation Progress](/add-donation-progress) documentation.

* **Dynamic Payment Item:** A calculator for Number/Product fields that updates the payable amount live. Read the [Dynamic Payment Item](/dynamic-payment-item) documentation.

## **E**

* **Entry:** A single form submission record you can view, filter, export, or refund. Read the [View Form Entries](/view-form-entries) documentation.

## **F**

* **Fee Recovery:** Lets you pass the gateway's transaction fee to the payer instead of absorbing it. Read the [Fee Recovery Field](/add-fee-recovery-field) documentation.

* **Feed (Integration Feed):** A configured connection added to a form's **Integrations** tab, like a Mailchimp feed mapping fields to a list.

* **Field:** The building blocks dragged onto a form, including General Input, Product, and Payment Method fields.

* **FluentCommunity Integration:** Connects Paymattic to [FluentCommunity](/integrate-fluentcommunity) to sell paid access to Spaces and Courses.

* **FluentCRM Integration:** Connects Paymattic to [FluentCRM](/integrate-fluentcrm) so new submitters are added as contacts automatically.

* **Fluent Support Integration:** Connects Paymattic to [Fluent Support](/integrate-fluent-support) to charge for support tickets.

* **Form:** Paymattic's core object, a drag-and-drop payment/donation form. Create one [from scratch](/create-form-from-scratch) or a [template](/simple-form-templates).

* **Form Restrictions & Scheduling:** Settings to cap submissions, set an active date/time window, or require login.

* **Form Template:** A pre-built form layout you can pick and customize. Read the [Form Templates](/simple-form-templates) documentation.

## **G**

* **Gift Aid:** A UK-specific donation field for charities to reclaim tax on donations. Read the [Gift Aid](/add-gift-aid) documentation.

* **GiveWP Migration:** A built-in tool that moves your GiveWP setup into Paymattic. Read the [GiveWP Migration](/givewp-migration) documentation.

* **Google Sheets Integration:** Connects Paymattic to [Google Sheets](/integrate-google-sheets), writing every submission to a spreadsheet.

* **Gutenberg Block:** A block-editor block for embedding a Paymattic form in a Gutenberg page or post.

## **H**

* **Hold Payment:** An authorize-now, capture-later mode for Stripe. Read the [Stripe Payment Hold](/stripe-payment-hold) documentation.

* **Honeypot:** A hidden field used as a lightweight anti-spam trap on your forms.

## **I**

* **Import / Export:** Import/export whole forms between sites, or export entries in bulk. Read the [Import Export Forms](/import-export-forms) documentation.

* **Integration:** A connection between Paymattic and a third-party service that routes form data automatically.

* **IP Logging:** Records a submitter's IP address on each entry; can be disabled for privacy. Read the [Disable IP Logging](/disable-ip-logging) documentation.

* **Item Quantity:** Lets a buyer select multiple units of one product. Read the [Item Quantity](/add-item-quantity) documentation.

## **L**

* **LearnDash Integration:** Connects Paymattic to [LearnDash](/integrate-learndash) to automate course enrollment and registration.

* **LifterLMS Integration:** Connects Paymattic to [LifterLMS](/integrate-lifterlms) to automate course enrollment and registration.

* **Live Mode / Test Mode:** A gateway toggle for processing real payments (Live) or trialing with sandbox credentials (Test).

* **LMS Integration:** The category of LearnDash, LifterLMS, and Tutor LMS integrations that sell course access.

## **M**

* **Mailchimp Integration:** Connects Paymattic to [Mailchimp](/integrate-mailchimp), sending contact info to your audience list.

* **Manage Subscriptions:** An admin screen for tracking recurring Offline Payment subscriptions manually. Read the [Manage Subscriptions](/manage-subscriptions) documentation.

* **Merge Tag / Shortcode:** A dynamic placeholder that pulls real submission data into emails and feeds.

* **Module / Addon:** A self-contained feature or connector you can enable per form, like User Registration.

* **Multiple Column Layout:** A container that places fields side-by-side to compact longer forms. Read the [Multiple Column Layout](/add-multiple-columns) documentation.

## **N**

* **Notification:** Automated alerts on form events, including Email, plus SMS/Slack/Telegram. Read the [Email Notifications](/setup-email-notifications) documentation.

## **O**

* **Offline Payment:** A payment method (bank transfer, cash) marked paid manually by the admin. Read the [Offline Payment](/collect-offline-payment) documentation.

* **One-time Payment:** A single, non-recurring charge, and the default payment type before Subscriptions.

## **P**

* **Paymattic:** A payment and donation WordPress plugin for building forms and accepting payments. Read the [Paymattic Introduction](/paymattic-introduction).

* **Paymattic Pro:** The paid tier adding subscriptions, more gateways, Coupons, Reports, and Pro integrations.

* **Payment Gateway:** A processor Paymattic connects to for charging cards, like Stripe or PayPal. Read the [All Payment Methods](/all-payment-method) documentation.

* **Payment Item Field:** The core field for listing what a visitor can buy or donate to. Read the [Payment Item Fields](/add-payment-item-fields) documentation.

* **Payment Method Field:** The field where a configured gateway is placed so visitors can pay. Read the [Payment Method Fields](/use-payment-method-fields) documentation.

* **Payment Summary:** Shows a running total of selected items, tax, and discounts. Read the [Payment Summary](/add-payment-summary) documentation.

* **PDF Feed / PDF Invoice:** Generates a PDF receipt and emails it after a successful payment. Read the [PDF Feed](/create-pdf-feed) documentation.

* **Product Field:** Fields used to sell products or collect donations. Read the [Product Fields](/use-product-fields) documentation.

## **R**

* **reCAPTCHA:** Google's widget for blocking automated form submissions. Read the [reCAPTCHA](/configure-recaptcha) documentation.

* **Refund:** An admin action to return funds via Payment Status or the Process Refund button. Read the [Refund Payments](/refund-payments) documentation.

* **Reports & Analytics:** A dashboard summarizing entries, revenue, and trends. Read the [Reports & Analytics](/view-reports-analytics) documentation.

## **S**

* **SCA (Strong Customer Authentication):** A European PSD2 security standard Paymattic supports for compliant card payments.

* **Slack Integration:** Connects Paymattic to [Slack](/integrate-slack), posting a notification on form submission.

* **Step Form:** A form split into multiple sequential pages. Read the [Step Forms](/create-step-form) documentation.

* **Subscription Payment:** A recurring charge on a repeating schedule, also called Recurring Payment. Read the [Subscription Payment](/add-subscription-payment-fields) documentation.

* **Sync Subscription Billing:** A User Dashboard permission to refresh billing status from the gateway. Read the [User Dashboard Module](/add-user-dashboard-module) documentation.

## **T**

* **Tabular Product Item:** Displays products in a Table, Grid, or Single Line layout. Read the [Tabular Product Item](/add-tabular-product-fields) documentation.

* **Tax Calculator:** Applies a percentage-based tax to a payment item. Read the [Tax Calculator](/add-tax-calculator) documentation.

* **Telegram Integration:** Connects Paymattic to [Telegram](/integrate-telegram) for instant channel/group notifications.

* **Tutor LMS Integration:** Connects Paymattic to [Tutor LMS](/integrate-tutor-lms) to automate course enrollment.

* **Twilio Integration:** Connects Paymattic to [Twilio](/integrate-twilio) for automated SMS notifications.

## **U**

* **Update Subscription Card:** A User Dashboard permission letting customers update their card themselves. Read the [User Dashboard Module](/add-user-dashboard-module) documentation.

* **User Dashboard:** A frontend portal for customers to view history and manage their own subscriptions. Read the [Add User Dashboard Module](/add-user-dashboard-module) documentation.

* **User Defined Amount:** Lets a payer type in their own custom payment amount. Read the [User Defined Amount](/add-user-defined-amount) documentation.

* **User Registration Integration:** Auto-creates a WordPress account when someone submits/pays a form. Read the [Create a User Registration Form](/create-user-registration-form) documentation.

* **User Roles & Permissions:** Assigns access levels controlling what admins/users can see or do. Read the [Manage User Roles](/manage-user-roles) documentation.

## **W**

* **Webhook:** Sends real-time form/payment data to an external URL on a form event. Read the [Webhook](/integrate-webhook) documentation.

## **Z**

* **Zapier Integration:** Connects Paymattic to [Zapier](/integrate-zapier), pushing submitted data to other connected apps.
